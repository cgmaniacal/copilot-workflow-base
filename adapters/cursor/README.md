# Cursor Adapter

Generates `.cursorrules` for projects onboarded with ai-workflow-overlay.

Cursor reads `.cursorrules` at the project root to provide persistent AI instructions across all sessions.

## What this adapter generates

| File | Description |
|------|-------------|
| `.cursorrules` | Cursor's persistent instructions file, containing the workflow and all agent docs |

The generated file includes:
1. A header comment noting it was generated by ai-workflow-overlay
2. The full contents of `core/workflow.md`
3. A separator
4. All `.md` files from `agent_docs/` concatenated with section headers (sorted alphabetically)

## When to regenerate

Regenerate after:
- Editing any file in `agent_docs/`
- Updating `core/workflow.md`

## How to regenerate

From the project root, run the onboarding script (which calls this adapter):

```bash
node scripts/onboard.mjs
```

Or call the adapter directly from a script:

```javascript
import { generateCursorConfig } from './adapters/cursor/generate.mjs';

generateCursorConfig(
  '/path/to/target-project',           // project being onboarded
  '/path/to/overlay/core',             // overlay's core/ directory
  '/path/to/target-project/agent_docs' // populated agent_docs in target project
);
```

## Notes

- If `agent_docs/` does not exist yet (early in onboarding), only the workflow content is written.
- `.cursorrules` is written directly at the project root — no subdirectory is created.
- No external dependencies — uses only Node.js built-ins.
