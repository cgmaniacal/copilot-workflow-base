# Copilot Adapter

Generates `.github/copilot-instructions.md` for projects onboarded with copilot-workflow-base.

GitHub Copilot is the primary agent for this workflow system. The core format is already Copilot-native, so this adapter mostly concatenates `core/workflow.md` with the populated `agent_docs/` files.

## What this adapter generates

| File | Description |
|------|-------------|
| `.github/copilot-instructions.md` | Copilot's persistent instructions file, containing the workflow and all agent docs |

The generated file includes:
1. A header comment noting it was generated by copilot-workflow-base
2. The full contents of `core/workflow.md`
3. A separator
4. All `.md` files from `agent_docs/` concatenated with section headers (sorted alphabetically)

## When to regenerate

Regenerate after:
- Editing any file in `agent_docs/`
- Updating `core/workflow.md`

## How to regenerate

From the project root, run the onboarding script (which calls this adapter):

```bash
node scripts/onboard.mjs
```

Or call the adapter directly from a script:

```javascript
import { generateCopilotConfig } from './adapters/copilot/generate.mjs';

generateCopilotConfig(
  '/path/to/target-project',        // project being onboarded
  '/path/to/overlay/core',          // overlay's core/ directory
  '/path/to/target-project/agent_docs' // populated agent_docs in target project
);
```

## Notes

- If `agent_docs/` does not exist yet (early in onboarding), only the workflow content is written.
- The `.github/` directory is created automatically if it does not exist.
- No external dependencies — uses only Node.js built-ins.
